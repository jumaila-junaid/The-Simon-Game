# 🎮 The Simon Game

A fun and interactive memory game built with HTML, CSS, JavaScript, and jQuery.

## 🌐 Live Demo

Play the game here: [The Simon Game](https://jumaila-junaid.github.io/The-Simon-Game/)

## 📖 About the Project

The Simon Game is a memory-based game where players must remember and repeat a sequence of colored buttons. The sequence becomes longer as the player progresses through the levels, making the game more challenging.

This project was built as part of The App Brewery web development course to practise JavaScript, DOM manipulation, event handling, and interactive web development.

## ✨ Features

- 🎨 Interactive colored buttons
- 🧠 Memory-based sequence challenge
- 📈 Increasing difficulty with each level
- 🔊 Button sounds and visual effects
- 🎮 Keyboard interaction to start the game
- 🔄 Restart the game after a game-over by pressing a key

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery

## 🚀 How to Play

1. Open the [Live Demo](https://jumaila-junaid.github.io/The-Simon-Game/).
2. Press any key on your keyboard to start the game.
3. Watch the colored button sequence carefully.
4. Repeat the sequence by clicking the buttons in the correct order.
5. Remember the previous sequence as a new color is added at each level.
6. Continue as long as you can remember the sequence correctly.
7. If the game ends, press a key to restart.

**Note:** Best played on a desktop or laptop because a keyboard is needed to start the game.

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/jumaila-junaid/The-Simon-Game.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
